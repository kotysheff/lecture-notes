# Конспекты лекций — ГУАП, гр. 4434

Архив конспектов по лекциям различных семестров («Программная инженерия»). Конспекты делаются на основе диктофонных записей лекций: черновая расшифровка дополняется и структурируется, неточности распознавания речи исправляются по смыслу, при необходимости — дополняются справочной информацией по теме.

## Как устроена заметка о лекции

Один файл = одна лекция, имя вида `YYYY-MM-DD-кратко-тема.md`. Метаданные (предмет, дата, преподаватель, тема, теги) — во frontmatter в начале файла. Шаблон для новой лекции — [`TEMPLATE.md`](./TEMPLATE.md).

Внутри папки каждого предмета — свой `README.md`: оргинформация по курсу (оценивание, формат сдачи лаб и т.п.) и таблица со списком конспектов этого предмета.
