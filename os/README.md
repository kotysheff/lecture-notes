# Операционные системы

[← Все предметы](../README.md)

**Преподаватель:** Поляк М.Д.
**Форма контроля:** экзамен
**Занятия:** лекция — вторник, 1 пара (поток 4431/4432/4434); лабораторная — понедельник, 6 пара

## Оценивание
- 100-балльная шкала: 85+ = «5», 70–84 = «4», 60–69 = «3»
- Учитываются: посещение лекций (1 балл за посещение), лабораторные, контрольные в ЛМС, экзамен
- Автомат на «5» получить сложно, но теоретически возможен

## Лабораторные
- Вариант задания (по номеру в журнале): 11
- Обязательна устная защита — нужно объяснить свой код и обоснование выбранных подходов; формальная сдача без понимания снижает оценку
- Использование ИИ/языковых моделей для изучения материала — разрешено и приветствуется
