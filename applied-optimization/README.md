## Особенности курса

- Порог: 50% = «3», 65% = «4», 80% = «5»
- Экзамен: 2 теоретических вопроса (5 б) + 1 задача (5 б)

## ЛР1 (гр. 4434)
Тема — «Визуализация одномерной оптимизации»: f(x) = (x−a)² + b·sin(cx); нужно выбрать 2 из 3 методов (золотое сечение / дихотомия / параболическая интерполяция), построить график функции с точками поиска и график сходимости методов.
Вариант 11: a = 1.3, b = 6.5, c = 2.3, отрезок [-1.9, 1.9], точность 0.0005
