# Проектирование баз данных

[← Все предметы](../README.md)

**Преподаватель:** Путилова Н.В.
**Форма контроля:** экзамен
**Занятия:** лекция — среда, 1 пара (поток); лабораторная — понедельник, 5 пара

## Особенности курса
- Курс на 2 семестра: 1-й семестр — реляционные БД, 2-й — нереляционные/объектные БД; всего 8 лабораторных за оба семестра
- Вариант задания: №11, тема «База данных сериалов»
- СУБД — любая реляционная/объектно-реляционная кроме встроенных (SQLite не подходит); в лекциях упор на PostgreSQL и MySQL
- Учебное пособие на весь курс: Путилова Н.В., Величко М.В. «Современные реляционные базы данных» (2025)

## Оценивание
- Экзамен + баллы за семестр = 100; 85–100 = «5», 70–84 = «4», 55–69 = «3»
- Автоматы: сданы все лабы → авто «3»; 50+ баллов за лабы за семестр → авто «5»
